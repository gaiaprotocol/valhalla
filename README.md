# Valhalla

**Valhalla** is an integrated messenger service for the most dedicated members of the Gaia Protocol community — holders of at least one **Gods NFT** or more than **10,000 \$GAIA tokens**.
Qualified holders unlock **God Mode**, gaining access to an exclusive, secure communication space.

## Cloudflare Build Cmd
```
NODE_ENV=production npx webpack --mode=production && cd firebase-messaging-sw && NODE_ENV=production npx webpack --mode=production --config webpack.config.js
```

## Features

* Exclusive access for qualified holders (Gods NFT or 10,000+ \$GAIA)
* Private and secure messaging
* Seamless, real-time communication
* Connect, share, and collaborate with fellow Gods and supporters
